# Maker Requests Module

The `maker-requests` module is a remote micro-frontend for the HDFC project.

## Purpose
This module is intended to display maker/checker workflows and request details.

## Files
- `src/App.js` - Main application component
- `src/index.js` - Module entry point
- `webpack.config.js` - Module Federation configuration
- `src/styles.css` - Module styling

## Usage
```bash
cd maker-requests
npm install
npm start
```

## Notes
- Loaded by `host-app` as part of the micro-frontend shell.
