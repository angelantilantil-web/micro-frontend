# AI Agent Module

This module provides a simple demo chatbot experience for the HDFC micro-frontend POC.

## Startup

```bash
cd ai-agent-module
npm install
npm start
```

## Features

- AI chatbot style interface
- Mock question and answer responses
- Suggested FAQs for quick demo interactions

## Notes

This module is built as a Webpack Module Federation remote and is exposed as `AIAgentApp`.
