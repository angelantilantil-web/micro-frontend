# Loans Module

The `loans-module` is a remote micro-frontend for the HDFC project.

## Purpose
This module provides UI for viewing and managing loan accounts.

## Files
- `src/App.js` - Main application component
- `src/index.js` - Module entry point
- `webpack.config.js` - Module Federation configuration
- `src/styles.css` - Styling for the module

## Usage
```bash
cd loans-module
npm install
npm start
```

## Notes
- The host app loads this module on the Loans route.
