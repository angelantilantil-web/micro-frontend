# Model Portfolio Configuration Module

The `model-portfolio-configuration` module is a remote micro-frontend for the HDFC project.

## Purpose
This module provides configuration screens for model portfolio settings.

## Files
- `src/App.js` - Main component
- `src/index.js` - Entry point
- `webpack.config.js` - Module Federation setup
- `src/styles.css` - Styling for the module

## Usage
```bash
cd model-portfolio-configuration
npm install
npm start
```

## Notes
- The host app loads this module when the portfolio configuration route is active.
