# VRO Uploads Module

The `vro-uploads` module is a remote micro-frontend for the HDFC project.

## Purpose
This module provides UI for uploading and managing VRO documents.

## Files
- `src/App.js` - Main component
- `src/index.js` - Entry point
- `webpack.config.js` - Module Federation configuration
- `src/styles.css` - Styling for the module

## Usage
```bash
cd vro-uploads
npm install
npm start
```

## Notes
- The module is loaded by `host-app` when the VRO Uploads route is selected.
