# Outgoing API Logs Module

The `outgoing-api-logs` module is a remote micro-frontend for the HDFC project.

## Purpose
This module displays logs for outgoing API calls.

## Files
- `src/App.js` - Main component
- `src/index.js` - Entry point
- `webpack.config.js` - Module Federation configuration
- `src/styles.css` - Styling for the module

## Usage
```bash
cd outgoing-api-logs
npm install
npm start
```

## Notes
- This module is loaded by `host-app` on the Outgoing API Logs route.
